## 4. Секції сайту

1. **Головна** — Вибір галузі купівлі/продажу.

2. **Каталог товарів** — Вибір товарів для купівлі.

3. **Продати товар** — Реклама для товару який хочеш продати.

4. **Про нас** — інформація про сайт та його основні можливості.

5. **Контакти** — інформація для зв'язку з адміністрацією сайту.
